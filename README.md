# Agent Omarchy Playbook

**给 Agent 看的 Omarchy 使用与配置指南。**

在 Omarchy 上遇到问题、尝试配置、验证效果，再把过程整理成 Agent 能执行的文章。你把文章交给 Agent，它就能先检查目标电脑，再按步骤配置、验证并交付结果。

这里专注 Omarchy，记录实际使用中的小技巧、配置方法和踩坑经历。每篇文章都写清适用版本、最终配置、验证方法和回滚方式。一次试验有效的结果，会注明验证范围。

## 开始使用

把下面这段话和目标文章链接交给你的 Agent：

> 请先阅读仓库的 AGENTS.md，再按指定文章为我的 Omarchy 系统完成配置。先核对版本和现有设置，备份后定向修改，保留我的其他个人配置。执行文章的验收步骤，报告实际修改、验证结果和回滚方法。遇到版本不兼容时先调查，不机械照抄命令。

Agent 入口：[执行与维护规范](AGENTS.md)。

## 每篇文章要回答什么

1. 解决什么问题，最终应该是什么体验？
2. 在什么 Omarchy 版本和软件组合上验证过？
3. Agent 应该先检查什么、备份什么？
4. 修改哪些文件，怎样保留已有个人设置？
5. 怎样确认配置真正生效，失败时怎样回滚？
6. 哪些做法已经试过但不值得复用？

## 补充文章

使用 [文章模板](templates/article.md)，按 [贡献指南](CONTRIBUTING.md) 整理。目录只列已有文章；新主题完成实测后再加入。

仓库不存放个人词库、聊天记录、登录凭证或系统配置全量备份。大模型文件从文章注明的上游来源下载并校验，不直接提交进仓库。
